Privacy policy

Last updated: 21 October 2026

What the app accesses

With the user's consent, Rainmeter Calendar uses the Google Calendar API and the Google Tasks API to read the user's calendars, events, task lists and tasks, and to create, update (mark tasks complete) and delete events and tasks when the user asks for it from the widget.

Where the data goes

All processing happens locally on the user's Windows computer. Calendar and task data is saved only in a local file used to draw the widget. The OAuth refresh token is stored on the same computer, encrypted with Windows DPAPI so that only the same Windows user can read it.

The app has no server. Data is never sent to the developer or to any third party, and is not sold, shared or used for advertising. The only network connections are to Google's APIs.

Google API Services User Data Policy

Rainmeter Calendar's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access and data

Users can revoke access at any time from myaccount.google.com/permissions. Deleting the widget's folder removes all locally stored data and the token.

Informativa in italiano (sintesi)

Il widget accede, con il consenso dell'utente, a calendari, eventi e attività Google per mostrarli e modificarli su richiesta. Tutto resta sul computer dell'utente: non esiste un server e nessun dato viene inviato allo sviluppatore o a terzi. L'accesso si revoca da myaccount.google.com/permissions.
