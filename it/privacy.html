A cosa accede l'app

Con il consenso dell'utente, Rainmeter Calendar usa la Google Calendar API e la Google Tasks API per leggere calendari, eventi, elenchi di attività e attività dell'utente, e per creare, aggiornare (segnare come completate le attività) ed eliminare eventi e attività quando l'utente lo richiede dal widget.

Dove vanno i dati

Tutta l'elaborazione avviene in locale sul computer Windows dell'utente. I dati di calendari e attività sono salvati solo in un file locale usato per disegnare il widget. Il refresh token OAuth è salvato sullo stesso computer, cifrato con DPAPI di Windows in modo che solo lo stesso utente Windows possa leggerlo.

L'app non ha un server. I dati non vengono mai inviati allo sviluppatore o a terzi, e non sono venduti, condivisi o usati per pubblicità. Le uniche connessioni di rete sono verso le API di Google.

Google API Services User Data Policy

L'uso e il trasferimento da parte di Rainmeter Calendar delle informazioni ricevute dalle API Google rispettano la Google API Services User Data Policy, compresi i requisiti di Limited Use.

Revoca dell'accesso e cancellazione dei dati

L'utente può revocare l'accesso in qualsiasi momento da myaccount.google.com/permissions. Eliminando la cartella del widget si cancellano tutti i dati salvati in locale e il token.
