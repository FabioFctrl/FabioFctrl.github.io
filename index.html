Rainmeter Calendar

Rainmeter Calendar is a personal desktop widget for Rainmeter on Windows. It shows a monthly view of the user's Google Calendar events and Google Tasks, and lets the user create, complete and delete events and tasks directly from the desktop.

The widget runs entirely on the user's own computer. It talks only to Google's official APIs, using an access token that is stored encrypted on that computer. There is no server and no third party involved.
